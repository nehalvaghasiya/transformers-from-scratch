A CPU replay recorded on **November 12, 2026 (America/Chicago)** matched the reference
results for both independent experiments. This records that replay; current software
status comes from rerunning the checks or [CPU CI](../.github/workflows/cpu.yml).

The replay used Python **3.12.12**, PyTorch **2.8.0+cpu**, NumPy **2.5.3** and two CPU
threads on Linux x86-64. Its lockfile SHA-256 was
`d9d11b7496fa23e62d3c152f40fbed690a0fa98ce7b08d966f4a317aeb8f7617`.

## Repeat the verification

Use the [locked CPU setup and software checks](../README.md#software-checks). For a full
experiment comparison, first restore the external historical SQL checkpoints and regenerate
the data as described in the [SQL guide](../finetuning/README.md#replay-the-historical-checkpoint).
Then run from repository root with fresh output directories:

```bash
uv run --no-sync pretraining data prepare --config pretraining/configs/ticket-pool.toml
uv run --no-sync pretraining benchmark --config pretraining/configs/ticket-pool.toml --output runs/ticket-replay
uv run --no-sync python scripts/verify_experiments.py --ticket-report runs/ticket-replay --output runs/verification
```

If the ticket run IDs already exist with a different source/config/data contract, use a
copy of the TOML configuration with a fresh `runs_dir`. Config paths resolve relative to
the TOML file. The comparison script regenerates SQL data, replays every SQL system and
writes metrics, predictions, intervals, figures and `comparison.json` into the chosen
output directory. Inspect its `status` and any recorded differences.

CI tests generate temporary model/data fixtures; they do not require versioned checkpoints.
Routine checks belong in CI or local outputs under ignored `runs/`. Old packaging receipts
and machine-specific verification files are archived locally under `runs/report-archive/`;
they are not needed by training, inference or tests. Generated root `reports/` output is
also ignored. Keep new curated benchmark evidence with its experiment rather than
committing another collection of transient verification receipts.
